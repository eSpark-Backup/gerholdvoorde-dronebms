# Gerhold Voorde - Drone BMS Circuit Design

## Project Requirements
Datasheet:
https://www.analog.com/media/en/technical-documentation/data-sheets/MAX17201-MAX17215.pdf 
Pcb design document:
https://www.analog.com/media/en/technical-documentation/user-guides/max1720xmax1721x-system-side-implementation-guide.pdf 


* All components to one side of the holes
* CSN CSP traces shorter
* No vias in CSN and CSP traces
* Holes smaller if needed
* Connect EP via CSN pin
* Change current sense resistor (2512): https://nl.farnell.com/yageo/pa2512fkf7w2u5e/res-r0025-1-2w-2512-metal-strip/dp/4169831 
* Meet design standard for production (clearance)
